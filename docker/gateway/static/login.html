Don't know the password?

It is generated on first boot and printed in the deploy logs of the service (Railway → your service → Logs, look for the framed REMOTE DESKTOP READY banner). With a volume attached it stays the same across restarts.

To choose your own, set the service variable DESKTOP_PASSWORD and redeploy. To change it later, update that variable, or run cloudpc-password set inside the container.

Phone and tablet tips

After signing in, use Add to home screen for a full-screen desktop. Rotate to landscape for more room, pinch to zoom, drag with two fingers to pan, and use the keyboard button in the control bar for typing.
